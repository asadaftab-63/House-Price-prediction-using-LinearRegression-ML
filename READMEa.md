# House Price Prediction using Linear Regression

## Project Overview
This project demonstrates a basic end-to-end Machine Learning workflow for predicting house prices using synthetic data.

## Technologies Used
- Python
- NumPy
- Pandas
- Scikit-learn
- Google Colab

## Features
- Area
- Number of Bedrooms
- House Age

## Workflow
1. Generate synthetic house data
2. Create feature matrix X and target y
3. Split data into training and testing sets
4. Train a Linear Regression model
5. Predict house prices
6. Evaluate using MAE, MSE and RMSE

## Important Note
The dataset is synthetic, and prices are generated using a predefined formula. The near-zero prediction error does not imply equivalent performance on real-world house-price data.

## How to Run
Open the `.ipynb` notebook in Google Colab and run the cells in order.
